1）Is My Data in Your Retrieval Database? Membership Inference Attacks Against Retrieval Augmented Generation

这是比较早明确提出 RAG retrieval database membership inference 的工作。它研究的是：攻击者能否通过 RAG 系统输出，判断某段文本是否存在于检索数据库中。论文强调 RAG 的 retrieval database 可能包含敏感或私有数据，攻击者可以在黑盒或灰盒设置下进行推断。

它和你方法的关系：

它：构造 prompt → 观察 RAG 输出 → 判断文档是否在库中
你：构造错误实体 → 观察是否恢复原实体 → 判断文档是否在库中

你的方法比它更偏 conflict-triggered recovery signal。

2）Generating Is Believing: Membership Inference Attacks against Retrieval-Augmented Generation

这篇提出了 S²MIA，核心思想是：如果目标样本存在于 RAG 外部数据库中，那么用该样本查询 RAG 后，生成内容会和目标样本有较高语义相似度。它重点关注 RAG 外部数据库的 membership privacy，并用生成文本与目标样本之间的 semantic similarity 做成员分数。

它和你方法的区别：

S²MIA：看生成文本和原文的语义相似度
你的方法：看模型是否把被篡改实体恢复为原始实体

所以你的信号更“硬”，更接近实体级证据，而不是整体语义相似度。

3）Mask-based Membership Inference Attacks for Retrieval-Augmented Generation

这篇和你的思路最接近。它提出 MBA（Mask-Based Attack）：先把目标文档中的部分词 mask 掉，然后让 RAG 系统预测 mask 内容。如果目标文档在知识库里，RAG 更容易检索到完整文档，从而准确填回被 mask 的词。

它和你方法的关系非常近：

MBA：把实体/词 mask 掉 → 看系统能不能补回来
你的方法：把实体改错 → 看系统能不能纠回来

可以说，你的方法是：

mask recovery → conflict recovery

相比 MBA，你的方法更自然，因为真实用户更可能输入“错误事实”或“待校对文本”，而不是显式 [MASK]。

4）RAG-leaks: Difficulty-calibrated Membership Inference Attacks on Retrieval-Augmented Generation

这篇指出，很多 RAG-MIA 方法依赖 response similarity，但相似度并不直接等于 membership，可能反映的是样本难度。它提出 DC-MIA，用 difficulty calibration 来校准成员分数。

这对你很重要，因为 reviewer 也可能质疑：

你的 CMS 高，是不是因为样本本身更容易被恢复？

所以你后面可以借鉴它的思想，做一个：

difficulty-calibrated CMS

比如用 non-member 邻近样本校准实体恢复难度。

5）E-MIA: Exam-Style Black-Box Membership Inference Attacks against RAG Systems

这是很新的工作，提出把目标文档中的可验证证据变成类似考试题，例如填空、单选、多选、判断题，再用 RAG 的答题分数作为 membership signal。它强调传统语义相似度信号容易重叠、不稳定，而 exam-style 的“硬证据问题”能增强区分度。

它和你的方法也很接近：

E-MIA：把文档事实变成题，看 RAG 会不会答对
你的方法：把文档事实改错，看 RAG 会不会纠正

你的方法可以被定位成：

correction-style evidence probing

和 E-MIA 的 exam-style probing 有明显关联，但不是同一个机制。
 
 6）Riddle Me This! Stealthy Membership Inference for Retrieval-Augmented Generation

 设计一种叫 Interrogation Attack（IA） 的方法，通过生成一组自然但与目标文档高度相关的问题，去询问 RAG 系统；如果系统能稳定答对，就推断目标文档可能在它的检索库里。它的核心不是让模型泄露原文，而是用“正常提问”的方式间接判断某个文档是否被 RAG 收录。
